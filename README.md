## Vercel'e yayınlama
1. Bu klasördeki tüm dosyaları bir GitHub deposuna yükleyin (index.html kökte olmalı).
2. vercel.com → Add New → Project → depoyu seçin → Deploy.
   Framework: "Other", Build Command ve Output Directory boş kalabilir.
   (Alternatif: klasörde `npx vercel --prod`)

## Telefona kurma
Adresi Chrome/Safari'de açın → menüden "Ana ekrana ekle".
